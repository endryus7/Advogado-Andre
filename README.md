# ⚖️ Dr. André Albani Lara
> Site institucional desenvolvido para o advogado criminalista André Albani Lara, com foco em transmitir credibilidade, apresentar sua atuação profissional e facilitar o contato de potenciais clientes.
> O visitante pode conhecer o advogado, entender as áreas de atuação, acompanhar o processo de atendimento, assistir conteúdos em vídeo e entrar em contato pelo WhatsApp ou formulário.

## Tecnologias

React · JavaScript · Vite · CSS Modules · Framer Motion · React Hook Form · Yup · EmailJS · Lucide React

---

## Funcionalidades

- Apresentação institucional do advogado e sua trajetória profissional
- Exibição das principais áreas de atuação em Direito Penal e Processo Penal
- Seção "Como Funciona" explicando cada etapa do atendimento jurídico
- Vídeos informativos para aproximar o visitante e esclarecer dúvidas frequentes
- Formulário de contato com validação (React Hook Form + Yup) e envio por e-mail via EmailJS
- Contato direto pelo WhatsApp
- Design totalmente responsivo com foco em dispositivos móveis
- Animações suaves utilizando Framer Motion
- Identidade visual personalizada desenvolvida com CSS Modules
